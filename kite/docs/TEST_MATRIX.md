# Test matrix

| Surface | Automated coverage | Manual live check still needed |
|---|---|---|
| AUSD amount parsing | Positive six-decimal amounts; zero, negative, exponent, comma and over-precision rejected | Compare displayed value to actual token balance on Monad testnet |
| Signed invoices | EIP-712 request signs/verifies; serializes/decodes; tampered amount invalidates signature; changed copy hash rejected; expiry and payload cap enforced; single-invoice details hash unchanged from the pre-schedule format | Share link across two browser sessions; verify from the payer session |
| Payment plans (installments) | Exact six-decimal split with remainder on the last installment (sums exactly to the total); due dates spaced by interval; per-installment 7-day grace; titles numbered and capped at 80 chars; each installment separately signed with one random plan ID; index, due date and count bound into the signed hash (tampering rejected); 400-day window only for scheduled installments; malformed schedules rejected | Pay installment 1 from the payer wallet, then confirm installments 2+ are still payable and verify the due-date text in the payer view |
| Mera derivation/session | Deterministic account derivation for same PRF bytes; separate output gives a different address; signing session copies its key and refuses signing after `end()` | Create and restore with supported passkey devices; confirm stable address after browser reload |
| Contact encryption | AES-GCM roundtrip; no plaintext in ciphertext; nonce changes; wrong key and tamper rejected; malformed/oversized data rejected | Add a real contact, lock, re-authenticate and decrypt on the same synced credential |
| Envio handler | `createTestIndexer()` simulates a `Transfer` and asserts chain/block/log identity, normalized addresses, timestamp, hash and exact integer value | Deploy the indexer; verify a new AUSD transfer appears through the hosted GraphQL endpoint |
| API boundary (in-process, `tests/server-api.test.ts`) | Health exposes only booleans and never echoes keys; Alchemy URL used when the server key is set and key absent from responses; MONAD_RPC_URL fallback restricted to http(s); wallet methods (`eth_accounts`) and unknown methods blocked; oversized raw transactions rejected; upstream failures return generic errors; Envio endpoint must be HTTPS, queries use parameterised variables, malformed/duplicate rows dropped; Kimi/Qwen/Hunyuan calls carry bearer auth, configured model and JSON mode; model output with extra fields rejected; non-HTTPS provider URLs refused; provider 429 propagated | Configure Alchemy, Envio, Kimi/Qwen/Hunyuan credentials and verify live status/output. These tests use stubbed upstreams; they are not sponsor-usage evidence |
| API process smoke (`tests/api.test.ts`) | Spawns the real server process; health, RPC allowlist, Envio endpoint refusal, AI validation | — |
| UI | Typecheck + Vite production build | Test at 390px and desktop; passkey flow on iOS Safari/Android Chrome; real testnet send/faucet |
| Smart contracts | No custom custody or settlement contract in the initial path; direct transfer uses Agora AUSD ERC-20 | Sponsor review and audit before any mainnet usage |

Run root tests with `npm test` (Node.js 24.x; Vitest is scoped to `tests/`). For Envio, from `indexer/` run `npm ci`, `npm run codegen`, `npm run typecheck`, then `npm test`. Passing local tests establish local behavior only; they are not a security audit or prize eligibility proof.
